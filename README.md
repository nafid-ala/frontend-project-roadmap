# Frontend Project Roadmap

Roadmap belajar frontend developer dengan pendekatan project-based learning. Repo ini dibuat untuk membantu kamu belajar sambil membangun proyek nyata, mulai dari dasar sampai siap membuat portfolio dan aplikasi frontend yang lebih kompleks.

## Tujuan repo ini
- Belajar frontend secara terstruktur
- Fokus pada proyek nyata, bukan hanya teori
- Menyediakan roadmap, aturan belajar, dan cheat sheet
- Membantu kamu memilih project yang sesuai level

## Cara pakai repo ini
1. Baca README ini terlebih dahulu
2. Buka file ROADMAP.md
3. Pilih project yang sesuai levelmu
4. Ikuti urutan belajar dari mudah ke sulit
5. Buat project, commit ke GitHub, dan upload hasilnya

## Struktur repo
- `README.md` — ringkasan repo
- `ROADMAP.md` — roadmap belajar fase per fase
- `PROJECTS.md` — daftar project dan level kesulitan
- `RULES.md` — aturan belajar agar konsisten
- `CHEATSHEET.md` — shortcut, command, dan catatan cepat

## Target belajar
- HTML, CSS, JavaScript
- DOM dan interaksi user
- API fetch
- React dasar sampai intermediate
- Styling modern (Tailwind/CSS)
- Git/GitHub
- Deployment (Vercel/Netlify)

## Timeline umum
- 1–2 bulan: HTML, CSS, JavaScript dasar
- 2–4 bulan: project frontend, React, API
- 4–6 bulan: dashboard, portfolio, app kompleks

## Level yang disarankan
- Pemula: landing page, portfolio, to-do app
- Menengah: notes app, weather app, dashboard
- Lanjut: ecommerce UI, admin dashboard, booking app

## Sumber belajar utama (Bahasa Indonesia)
- Web Programming UNPAS
- Kelas Terbuka
- Programmer Zaman Now
- BuildWith Angga
- Codepolitan
- MDN Web Docs

## Aturan belajar yang penting
- Fokus pada satu bahasa dulu: JavaScript
- Jangan pindah stack sebelum 2–3 project selesai
- Buat project kecil dulu, lalu naik level
- Tulis dokumentasi singkat untuk setiap project
- Commit secara rutin setiap progres
- Gunakan GitHub sebagai portofolio

## Project yang direkomendasikan
