# Learning Plan 8 Minggu

Plan belajar ini dirancang agar kamu bisa belajar frontend secara konsisten dan fokus.

## Minggu 1–2: HTML, CSS, JavaScript dasar
Tujuan:
- paham struktur web
- paham styling dasar
- paham konsep pemrograman sederhana

Aktivitas:
- belajar HTML dan CSS dasar
- buat landing page sederhana
- buat kalkulator sederhana
- belajar JavaScript dasar

## Minggu 3–4: JavaScript lanjutan + project kecil
Tujuan:
- paham DOM, fetch API, localStorage

Aktivitas:
- buat to-do app
- buat notes app
- buat weather app
- sertakan README dan GitHub

## Minggu 5–6: React dasar
Tujuan:
- paham component, props, state, hooks

Aktivitas:
- belajar React
- buat portfolio React
- buat dashboard sederhana
- mulai belajar routing

## Minggu 7: React lanjutan + UI modern
Tujuan:
- paham api integration dan reusable component

Aktivitas:
- buat blog UI atau dashboard admin
- tambah form dan loading state
- styling dengan CSS modern

## Minggu 8: Deployment + portfolio
Tujuan:
- siap untuk dipresentasikan

Aktivitas:
- pilih 2 project terbaik
- revisi UI
- deploy ke Vercel/Netlify
- buat README yang rapi

## Checklist akhir
- [ ] 2–3 project selesai
- [ ] GitHub aktif dan teratur
- [ ] portfolio dibuat
- [ ] salah satu project sudah di-deploy
- [ ] bisa menjelaskan project yang dibuat

---

Konsistensi lebih penting daripada cepat. Yang penting adalah terus maju, satu langkah setiap hari.
