# Aturan Belajar Frontend

Aturan ini dibuat supaya kamu belajar dengan disiplin dan konsisten. Fokusnya bukan hanya menonton video, tetapi membangun kemampuan nyata.

## 1. Pakai project-based learning
Belajar frontend akan lebih cepat jika kamu langsung membuat project. Teori hanya membantu saat kamu butuh konsep.

## 2. Satu teknologi dulu
Jangan terlalu banyak pindah stack sekaligus. Pilih satu fokus:
- HTML/CSS/JS dulu
- lalu React
- lalu styling modern

## 3. Selesaikan project kecil dulu
Jangan langsung ambil project besar. Mulai dari:
- landing page
- portfolio
- to-do app
- notes app

## 4. Setiap project harus memiliki hasil yang jelas
Setiap project minimal harus memiliki:
- UI yang bisa dibuka di browser
- struktur folder yang rapi
- README singkat
- GitHub repository

## 5. Commit secara rutin
Setiap kali ada progres, commit. Ini membantu melatih konsistensi dan dokumentasi kerja.

Contoh commit:
```bash
git add .
git commit -m "Menambahkan header hero section"
```

## 6. Jangan takut error
Error adalah bagian dari proses belajar. Cari penyebabnya, baca error, lalu perbaiki. Ini cara paling efektif untuk berkembang.

## 7. Tulis catatan kecil
Catat:
- konsep baru yang dipelajari
- fitur yang berhasil dibuat
- bug yang diselesaikan
- hal yang mau ditingkatkan

## 8. Fokus ke portofolio
Project yang bagus bukan hanya project yang benar-benar bisa jalan, tapi juga yang bisa ditunjukkan ke orang lain.

## 9. Belajar dari dokumentasi resmi
Dokumentasi resmi lebih aman dan lebih terpercaya daripada sekadar copy paste tutorial.

## 10. Konsisten lebih penting dari cepat
Belajar 1 jam setiap hari lebih baik daripada 10 jam hanya sekali seminggu.

## Slogan belajar
Belajar frontend itu bukan soal pintar sekali, tapi soal konsisten dan mau mengulang.

## Contoh rutinitas harian
- 30 menit: materi atau dokumentasi
- 60–90 menit: project / coding
- 15 menit: review dan catatan

## Checklist belajar harian
- [ ] belajar teori singkat
- [ ] coding project
- [ ] fix bug yang muncul
- [ ] commit hasil kerja
- [ ] catat pembelajaran hari ini

---

Gunakan prinsip ini setiap hari sampai project benar-benar terbentuk dengan kualitas yang baik.
