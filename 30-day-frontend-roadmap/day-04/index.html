# 30-Day Frontend Roadmap Ini adalah roadmap belajar frontend yang fokus pada progres nyata dan efisien. Tujuannya bukan hanya teori, tetapi menghasilkan project nyata yang bisa masuk portfolio. ## Struktur folder ```bash 30-day-frontend-roadmap/ ├── README.md ├── day-01/ │ └── index.html ├── day-02/ │ └── index.html ├── day-03/ │ └── index.html ├── day-04/ │ └── index.html ├── day-05/ │ └── index.html ├── day-06/ │ └── index.html ├── day-07/ │ └── index.html ├── day-08/ │ └── index.html ├── day-09/ │ └── index.html ├── day-10/ │ └── index.html ├── day-11/ │ └── index.html ├── day-12/ │ └── index.html ├── day-13/ │ └── index.html ├── day-14/ │ └── index.html ├── react-basics/ │ ├── index.html │ ├── app.js │ └── README.md ├── todo-app/ │ ├── index.html │ ├── style.css │ ├── script.js │ └── README.md ``` ## Target utama - Menguasai JavaScript dasar dan DOM - Memahami localStorage dan API - Membuat to-do app yang fungsional - Mulai React dasar - Membuat portfolio kecil dari project yang sudah dibuat ## Jadwal harian ### Day 1–3: DOM dan interaksi dasar - belajar event listener - belajar form submit - latihan ketik dan cara kerja DOM ### Day 4–7: JavaScript logic dan array - function - array - object - loop - event handling ### Day 8–14: project kecil dan dinamika data - counter app - notes app - localStorage - to-do app dasar - filter task ### Day 15–21: React dasar - component - props - state - useState - useEffect - form input di React ### Day 22–30: polishing + deployment - styling modern - membuat portfolio - deploy ke Vercel/Netlify - review dan refactor ## Aturan belajar - Fokus satu task per hari - Jangan hanya menonton, tapi coding - Simpan hasil di GitHub - Commit setiap progres - Jawab dengan output nyata: halaman yang bisa dibuka di browser ## Tips penting - 1 jam belajar + 2 jam coding lebih baik daripada 10 jam menonton video - Project to-do app adalah target utama - React baru dimulai setelah JavaScript dan DOM cukup kuat ## Untuk project utama Project utama yang harus kamu selesaikan adalah: - `todo-app` Fitur yang diharapkan: - tambah task - hapus task - checklist task - simpan ke localStorage - filter task - validasi input ## Goal akhir Pada hari ke-30, kamu mampu: - membangun project frontend lewat JavaScript - memahami DOM dan API - membuat to-do app yang bisa dipakai - tahu bagaimana cara lanjut ke React - memiliki portfolio di GitHub --- Mulai dari folder `day-04` dan lanjutkan ke folder berikutnya. Jangan buru-buru pindah ke React sebelum to-do app dasar selesai.
