# 30-Day Frontend Roadmap

Folder ini dibuat untuk membantu kamu belajar frontend dengan tugas yang terarah dan project nyata.

## Tujuan
- Belajar JavaScript, DOM, dan API
- Menyelesaikan project kecil seperti to-do app
- Meningkatkan kemampuan coding lewat latihan harian

## Struktur folder
```bash
30-day-frontend-roadmap/
├── README.md
├── day-01/
│   └── index.html
├── day-02/
│   └── index.html
├── day-03/
│   └── index.html
├── todo-app/
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── README.md
```

## Cara pakai
1. Buka folder `day-01`
2. Buka file `index.html` di browser
3. Lakukan tugas sesuai hari
4. Setelah hari ke-3, lanjut ke folder `todo-app`
5. Kerjakan project to-do app sampai selesai

## Target akhir 30 hari
- Paham JavaScript dasar
- Paham DOM dan event listener
- Paham lokalStorage
- Paham fetch API
- Mampu membuat to-do app sederhana
- Mampu lanjut ke React

## Catatan penting
- Jangan terburu-buru pindah materi
- Fokus pada satu tugas per hari
- Simpan hasil kerja di GitHub
