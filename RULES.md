# Daftar Project Frontend

Daftar project ini dibuat agar kamu bisa belajar frontend sambil membangun sesuatu yang nyata. Pilih satu project sesuai levelmu, selesaikan sampai bisa berjalan, lalu lanjut ke project berikutnya.

## Level 1: Pemula

### 1. Portfolio Pribadi
Deskripsi:
- halaman profil singkat
- section biodata
- project yang pernah dibuat
- kontak

Skill yang dipelajari:
- HTML
- CSS
- responsive layout
- basic design

### 2. Landing Page Sederhana
Deskripsi:
- hero section
- fitur
- testimoni
- CTA

Skill:
- layouting
- spacing
- typography
- button styling

### 3. Kalkulator Sederhana
Deskripsi:
- tombol angka
- operasi dasar
- hasil kalkulasi

Skill:
- JavaScript
- event handling
- DOM

### 4. Form Login/Register
Deskripsi:
- input username/password
- validasi sederhana
- tampilan clean

Skill:
- form handling
- validation
- CSS styling

## Cara memilih project
- Jika baru mulai: ambil project Level 1
- Jika sudah paham dasar: pilih Level 2
- Jika sudah siap React: pilih Level 3
- Jika sudah kuat UI: pilih Level 4

## Tips penting
- Selesaikan satu project sampai benar-benar jalan
- Jangan terlalu banyak pindah project sebelum selesai
- Simpan hasil project di GitHub
- Tulis README sederhana untuk tiap project
- Setelah selesai, jadikan itu portfolio

---

Kalau sudah selesai project awal, lanjut ke file `ROADMAP.md` untuk melihat materi berikutnya.
